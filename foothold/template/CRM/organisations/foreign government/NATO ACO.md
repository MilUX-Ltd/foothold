# NATO ACO — Allied Command Operations

## Summary

NATO Allied Command Operations. Operational command for NATO military operations, headquartered at Supreme Headquarters Allied Powers Europe (SHAPE), Mons, Belgium. Headed by SACEUR (Supreme Allied Commander Europe).

ACO is responsible for the planning and execution of all NATO military operations. Sister command to NATO ACT (Allied Command Transformation), which handles capability development and doctrine.
