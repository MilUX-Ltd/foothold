# Home Office

## Summary

Lead UK government department for immigration, drugs policy, crime, fire, counter-terrorism, and police. Key defence-innovation-relevant units include the Homeland Security Group and [[CRM/organisations/government/Accelerated Capability Environment (ACE)|Accelerated Capability Environment (ACE)]].

## Key units

- **Homeland Security Group.**
- [[CRM/organisations/government/Accelerated Capability Environment (ACE)|Accelerated Capability Environment (ACE)]] — partnership between public and private sectors with access to 260+ organisations and experts.
- **National Protective Security Authority** — protective security advice; security clearance policy.
- **Joint Security and Resilience Centre.**
