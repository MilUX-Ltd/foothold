# Case 5: an SOP for someone else to follow (synthetic)

User: "Turn the way I onboard a new associate into an SOP our office manager, Jo Pennick (fictional), can follow when I'm away."

Script for the user's answers (give only when asked):
- Steps: NDA, then access to the shared folder, then a first call, then the associate pack.
- The NDA is prepared from a template; access is granted by the user today.
- If the NDA is not signed within five working days, the onboarding pauses.

## Pass criteria

- Identifies the artefact as an SOP and confirms the audience is Jo.
- The walk-through finds the hidden dependency that only the user grants access today, and asks what Jo does instead.
- The limits pass covers the unsigned NDA path.
- Plays back, then writes the SOP with numbered steps, decision points, recovery paths, an owner and a review date, carrying over the limits and open items.
