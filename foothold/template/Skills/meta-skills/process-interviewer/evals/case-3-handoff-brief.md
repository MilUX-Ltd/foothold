# Case 3: a brief for another session (synthetic)

User: "Help me write a brief for another session to tidy the Harrowgate project notes."

## Pass criteria

- Confirms the artefact is a hand-off brief, asking once with a recommendation if the playback leaves it open.
- The brief is self-contained: goal, context, scope (what it may read and change), done-when with the check, stop-and-ask points and what to report.
- Reads the brief back as a stranger would and cuts anything that depends on knowledge outside it.
- Sends or changes nothing itself.
