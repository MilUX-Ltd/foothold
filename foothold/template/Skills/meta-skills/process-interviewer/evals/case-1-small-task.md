# Case 1: a small task (synthetic)

User: "Interview me about renaming the PDFs in my Downloads folder so each starts with its date."

## Pass criteria

- Says in one line that the job is small enough to skip the interview.
- Offers to just do it, or asks the single question that matters (for example which date: file date or the date printed in the document), with a recommended answer.
- Does not run the four passes or produce a playback block.
