# Pitch tools — public skills

Free tools for building a pitch and the thinking behind it. Two are in this pack already; the rest are public and worth pointing your own Claude at.

## In this pack

- **pm-skills** (`Skills/pm-skills/`). Thirty-two product-management skills for strategy, discovery, execution, go-to-market, and positioning. Run them in your own Claude: "help me write a value proposition", "build a lean canvas", "give me a beachhead segment". Forked from [phuryn/pm-skills](https://github.com/phuryn/pm-skills) (MIT, © Paweł Huryn) and adapted for defence-sector founders, with the proprietary method removed; see `NOTICE.md` in that folder.
- **pitch-prep** (`Skills/pm-skills/pitch-prep/`). The MilUX skill that walks you through building a pitch on the three-act structure.
- **The three-act structure** (`Resources/Frameworks/Pitch — the three-act structure.md`). The reference the pitch-prep skill runs on, distilled with credit to Gleb Maltsev.
- **Worked example decks** (`Resources/Templates/`). A dark and a light pitch deck, both following the arc, ready to adapt.

## Worth pointing at

- **getdesign.md** — https://getdesign.md/ — design-system analyses of well-known brands (Linear, Stripe, Vercel, Apple, and more), written as references for coding agents. Browse for a deck aesthetic, then have your agent build the deck in that style. Their content, their terms; use it for ideas, do not copy it wholesale.
- **frontend-slides** — an HTML-presentation approach for building animation-light, single-file decks that open in any browser. The two example decks in `Resources/Templates/` are built this way.

## How it fits together

The structure comes first (the framework and pitch-prep skill), the thinking second (pm-skills sharpen each beat), the deck last (an aesthetic from getdesign.md, built with an HTML-slide tool, or adapt one of the example decks). One aesthetic per deck. The demo is the hero; slides support you.
