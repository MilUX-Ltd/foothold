# Defence Events Calendar

The recurring UK and international defence events worth tracking. Each series with substantive content has its own page in `Intelligence/events/<Series>/`. Use this page as the navigation surface; create dated event notes inside the series folder as you attend.

## Regional cluster events

The [[CRM/networks/Regional Defence and Security Clusters/Regional Defence and Security Clusters|Regional Defence and Security Clusters]] each run a calendar of regional events through their RFCA-convened steering groups. The closest event programme to a defence-tech founder is typically their home cluster (SCRDSC, SWRDSC, London RDSC, etc.).

## How to use this calendar

- Pre-event: create a dated event note inside the relevant series folder (`Intelligence/events/<Series>/YYYY-MM-DD <Series> — <Event Name>.md`) per the [[Intelligence/events/Events Guide|Events Guide]].
- During the event: capture observations, quotes (with Chatham House Rule applied where stated), and contacts.
- Post-event: link attendees to their CRM contact pages, link organisations to their CRM org pages, and surface any follow-up actions.
