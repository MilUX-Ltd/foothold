# Dynamic Markets

## Summary

**Dynamic Markets / Dynamic Purchasing Systems (DPS).** MOD commercial routes that allow ongoing supplier entry throughout the life of the system, rather than fixed framework windows. Suppliers can apply to join at any time, and individual procurements run as competitions among DPS members.

## Operating model

Unlike traditional frameworks (which have a fixed supplier list set at PQQ), Dynamic Markets and DPS accept new supplier applications throughout. The buyer runs structured competitions among the current member set per procurement.
