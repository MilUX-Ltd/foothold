# Technology Services (TCS)

## Summary

**Technology Services (TCS).** Crown Commercial Service umbrella framework for technology services — network, cloud, cyber, digital, and data services. Currently in its third iteration (TCS3 / Technology Services 3) with several specialised sub-lots, including the digital and IT professional services lane used by defence buyers via [[Intelligence/defence-landscape/Frameworks/Digital and IT Professional Services (DIPS)|DIPS]].

## Operating model

Sub-lots:

- **Technology Services 3.** Overarching technology services lot.
- **Cyber Security Service 3.** Cyber security services.
- **Cloud Compute 2.** Cloud compute capacity.
- **Digital and IT Professional Services (DIPS).** IT professional services lane (~£1.2bn ceiling, used by Defence Digital).
- **Network Services 3.** Network and connectivity services.
- **Big Data and Analytics.** Data services.

Buyers select the relevant sub-lot and run a CCS-compliant competition.
