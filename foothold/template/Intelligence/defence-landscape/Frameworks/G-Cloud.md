# G-Cloud

## Summary

**G-Cloud.** Crown Commercial Service (CCS) framework for cloud computing services. Allows UK public sector organisations to procure cloud hosting, software, and support from accredited suppliers via the Digital Marketplace. Iterates on a regular refresh cycle (G-Cloud 12, 13, 14, and onwards).

## Operating model

Call-off via the Digital Marketplace. Three service categories: Cloud Hosting (IaaS / PaaS), Cloud Software (SaaS), and Cloud Support. Buyers run a short, structured competition against shortlisted suppliers; suppliers publish standardised service descriptions, pricing, and SLAs upfront.
