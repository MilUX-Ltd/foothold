# MORPHEUS Test & Reference Centre (MTRC)

## Summary

MTRC is an Authority-owned test facility under MOD TacSys / Tech Office. Provides independent test, evaluation, acceptance and quality assurance services to the wider Land CIS Organisation and the C4I sub-portfolio.

## Characteristics

- Flexible **Authority-owned** facility.
- Used for experimentation and integration.
- Reduced ITAR restrictions due to Crown Servant staffing.

## Benefits (as stated)

- Enables more efficient management by supporting the release / deployment process.
- Directly enables capability timelines to be improved through more effective testing and trialling.
- Enables capability integration by providing a test environment for new capability to be integrated within.
