# Land Systems Reference Centre (LSRC)

## Summary

LSRC is a MOD test and reference centre under TacSys / Tech Office. Provides through-life CIS test and reference services, plus test/integration/transition capability assuring release packages for the Defence Network and operations/exercises. Centrally funded by Army HQ; **free to use** for all MOD and MOD-sponsored projects across all Front-Line Commands.

## Services

- Through-life "System of Systems" CIS Test and Reference service.
- Test, integration and transition capability assuring release packages onto the Defence Network and supporting operations and exercises.
- Support for deployed and base ICT capabilities.
- Support not just for the Land Environment but all Front-Line Commands.

## Benefits (as stated)

- Bespoke support: testing accommodation, off-site support, or full release-and-assurance service.
- Centrally funded by Army HQ; free to use for MOD and MOD-sponsored projects.
