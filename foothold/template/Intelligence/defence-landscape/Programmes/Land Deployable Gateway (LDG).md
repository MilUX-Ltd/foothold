# Land Deployable Gateway (LDG)

## Summary

LDG provides an in-service, low-threat gateway facilitating secure information exchange between UK TacCIS (BCIP) and UK OpCIS and Coalition partners. The current in-service version (**LDGv1**) is fully Commercial-off-the-Shelf hardware in bespoke ruggedised transit cases. Programme is delivering **LDGv2** into service in **Q3 2025**.

## Versions

### LDGv1 (in service)

- Fully CoTS hardware; bespoke ruggedised transit cases.
- Fleet of **28 units** in support of the user community.
- Software obsolescence addressed; ongoing maintenance to BaU through to LDGv2 transition.
- Interoperability services: Chat, Situational Awareness, Email, Operational Staff Work, Geospatial Information (Web Map Services).

### LDGv2 (entering service Q3 2025)

- Medium-threat gateway with enhanced security features.
- Addresses hardware, software and architectural obsolescence.
- Aligned to **JSP 604 / Secure by Design** and **Federated Mission Network (FMN)**.
- Reduced complexity for the user; greater automation.
- Feeds from additional Situational Awareness sources.
